# 📈 Monitor de Cotações em Python (API + Pandas)

Este projeto realiza a extração automática de cotações de moedas em tempo real utilizando a API pública AwesomeAPI, processa e organiza os dados com a biblioteca **Pandas** e gera relatórios organizados.

## 🚀 Tecnologias Utilizadas
* **Python 3**
* **Requests:** Para consumo da API REST HTTP.
* **Pandas:** Para manipulação, limpeza e organização dos dados.
* **Git/GitHub:** Para controle de versão e documentação.
